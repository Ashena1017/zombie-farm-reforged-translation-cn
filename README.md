# Zombie Farm Reforged 汉化

把网页游戏 [Zombie Farm Reforged](https://zombiefarmreforged.com/) 的界面翻译成简体中文的 Tampermonkey 用户脚本。

**当前版本：1.0.3**

装上它，游戏里的英文就都变成中文了：菜单、提示、倒计时、战斗文字、道具说明，连画在画布上的字也会翻译。
词库整个装在脚本里，不联网、不调用翻译服务，也不碰你的账号和存档。

---

## 功能

- **页面与动态提示翻译**：菜单、弹窗、按钮、倒计时、任务、商店说明等持续新增的文案。
- **Canvas 游戏文字**：战斗与场景里绘制在画布上的文字也会翻译。
- **属性与说明**：僵尸属性、技能说明、道具效果等。
- **商店中文搜索联想**：在商店搜索框输入中文，选中候选后按商品英文原名执行**原生搜索**。选择候选只触发搜索，**不会购买**商品；联想限定在当前商店分类内。
- **可拖动翻译图标**：右下角的小图标可拖动到不遮挡游戏的位置，位置会被记住。
- **默认开启中文**：安装后即为中文。点击图标在中文 / 原文之间切换，选择会被记住。

## 隐私

- 词库随脚本内嵌，**不上传任何游戏数据，也不连接翻译 API**。
- 不读取、不上传账号凭据，不修改游戏存档。
- 只改写你屏幕上显示的文字；玩家名称、自定义僵尸名称和你的输入**保持原样**。

图片里固化的英文、第三方登录页面保留原样。

## 安装

### 电脑：Edge + Tampermonkey

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展。
2. 从本仓库 [Releases](../../releases) 下载 `ZFR在线网页版-纯汉化脚本.zip`。
3. 打开 Tampermonkey 管理面板 → **实用工具** → 在「导入」处选择该 ZIP，确认导入其中的用户脚本。
4. 确认「Zombie Farm Reforged 纯汉化」已启用，然后打开或刷新 <https://zombiefarmreforged.com/>。

也可以直接把 `zombie-farm-translation.user.js` 拖进浏览器安装，或在 Tampermonkey 里新建脚本后粘贴其内容。
脚本使用页面上下文（`@sandbox raw`），请使用支持该注入方式的新版 Tampermonkey。

### 手机：Via 浏览器

1. 下载并解压 ZIP，得到 `zombie-farm-translation.user.js`。
2. 打开 Via 的 **设置 → 脚本**，点击 **+ → 导入脚本**，选择该 JS 文件。
3. 确认脚本已启用，打开或刷新游戏页面。

> 导入的是 **`.user.js` 脚本，不是 ZIP 压缩包**。不同 Via 版本的菜单名称可能略有差异；手机真机兼容性尚未逐一验证。

## 使用

- 翻译**默认开启**，安装后刷新页面即为中文。
- 点击右下角图标切换中文 / 原文；**按住可拖动**，松手后位置会被保存。
- 脚本只在 `https://zombiefarmreforged.com/*` 上运行；若在已经打开的游戏里直接粘贴执行，请刷新页面让脚本在启动时加载。

## 常见问题

**看不到翻译图标？**
确认脚本已启用并刷新游戏页面；脚本只匹配 Zombie Farm Reforged 的 HTTPS 页面。

**点开了中文，但还有英文？**
先确认当前处于中文状态，再核对 Tampermonkey 里安装的脚本版本。图片内绘制的文字、第三方登录界面，以及上游新加、词库尚未覆盖的文案可能仍显示英文。

**商店中文搜索没有候选？**
先进入对应的商店分类；联想只搜索**当前分类**内的商品名称。

**翻译没生效 / 部分菜单是英文？**
请确认安装的是最新版本。上游更新会新增文案，旧版本脚本不含这些词条。

## 词库与构建

翻译词库**内嵌在脚本中**，运行时不需要联网、不需要 API Key，也不调用任何在线翻译服务：

- 词条来源以原版游戏官方简体中文语言包为参考，并补译重制版新增内容。
- 当前词库规模：**4,330 条词条、617 条模板、582 个商店名**。
- 脚本为单文件产物，由构建流程从词库生成；`dist/` 下的文件是构建输出，请勿直接编辑。
